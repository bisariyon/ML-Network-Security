# Documentation

## Detailed Explanations

### [Data Ingestion](./docs/data_ingestion.md)

Covers:

- ingestion workflow
- MongoDB data fetching
- train-test split
- artifact generation
- runtime flow

---

### Constants File

Contains reusable constants used across the training pipeline such as:

- database names
- artifact folder names
- file names
- train-test split ratio
- target column names

File:

```txt
src/constants/training_pipeline_constants.py
```

---

### Config Entity

Contains configuration classes that dynamically create runtime paths for pipeline components.

Examples:

- `TrainingPipelineConfig`
- `DataIngestionConfig`

File:

```txt
src/entity/config_entity.py
```

---

### Artifact Entity

Contains artifact classes used to store outputs generated by different pipeline stages.

Example:

- `DataIngestionArtifact`

File:

```txt
src/entity/artifact_entity.py
```
